## 1. 变更目标

1. 跑腿任务发布时支持上传 1～3 张图片。
2. 跑腿任务大厅卡片展示首张图片作为缩略图。
3. 跑腿任务详情页以平铺方式展示全部图片。
4. 个人空间支持头像上传。


## 2. 数据库新增字段

| 表 | 字段 | 类型 | 说明 |
|---|---|---|---|
| `task` | `image_urls` | TEXT | 逗号分隔的图片 URL |
| `product` | `image_urls` | TEXT | 逗号分隔的图片 URL |
| `user` | `avatar_url` | TEXT | 头像 URL |


## 3. 新增接口

### 3.1 图片上传

| | |
|---|---|
| 路径 | `POST /api/upload/image` |
| 权限 | 登录 |
| 用途 | 任务/商品发布时上传图片 |
| 请求类型 | `multipart/form-data` |
| 请求字段 | `file`（图片文件） |

请求示例：

POST /api/upload/image
Content-Type: multipart/form-data

file: [图片二进制数据]

成功响应：

{
  "code": 0,
  "msg": "ok",
  "data": {
    "url": "https://example.com/images/xxx.jpg"
  }
}

失败响应：

| HTTP | msg | 触发条件 |
|---:|---|---|
| `400` | 图片格式不支持 | 非图片格式 |
| `400` | 图片超过大小限制 | 超过 5MB |
| `401` | 请先登录 | 未登录 |

### 3.2 头像上传

| | |
|---|---|
| 路径 | `POST /api/users/me/avatar` |
| 权限 | 登录 |
| 用途 | 当前用户上传头像 |
| 请求类型 | `multipart/form-data` |
| 请求字段 | `avatar`（图片文件） |

请求示例：

POST /api/users/me/avatar
Content-Type: multipart/form-data

avatar: [图片二进制数据]

成功响应：

{
  "code": 0,
  "msg": "ok",
  "data": {
    "avatarUrl": "https://example.com/avatars/xxx.jpg"
  }
}

失败响应：

| HTTP | msg | 触发条件 |
|---:|---|---|
| `400` | 图片格式不支持 | 非图片格式 |
| `400` | 图片超过大小限制 | 超过 5MB |
| `401` | 请先登录 | 未登录 |


## 4. 已有接口字段扩展

### 4.1 任务列表

`GET /api/public/tasks` 返回字段增加 `imageUrls`

{
  "id": 1,
  "title": "帮取快递",
  "imageUrls": "https://example.com/img1.jpg,https://example.com/img2.jpg"
}

### 4.2 任务详情

`GET /api/public/tasks/{id}` 返回字段增加 `imageUrls`

{
  "id": 1,
  "title": "帮取快递",
  "imageUrls": "https://example.com/img1.jpg,https://example.com/img2.jpg"
}

### 4.3 发布任务

`POST /api/tasks` 请求体增加 `imageUrls`（选填）

{
  "title": "帮取快递",
  "imageUrls": "https://example.com/img1.jpg,https://example.com/img2.jpg"
}

### 4.4 个人资料

`GET /api/users/me` 返回字段增加 `avatarUrl`

{
  "id": 2,
  "username": "爱丽丝",
  "avatarUrl": "https://example.com/avatars/alice.jpg"
}

## 7. 前端交互验收

1. 跑腿发布页预览卡片可点击上传图片，最多 3 张。

3. 大厅卡片显示首张图片作为缩略图。
4. 详情页以平铺方式展示全部图片。

6. 头像上传后立即预览，上传成功后刷新显示。

## 8. 恢复默认头像

### 8.1 功能说明

用户上传头像后，可以随时切换回默认首字母头像。

### 8.2 接口扩展

`PUT /api/users/me` 请求体支持 `avatarUrl` 字段传空字符串：

```json
{
  "avatarUrl": ""
}
```

### 8.3 前端交互

1. 鼠标悬停头像 → 显示遮罩层
2. 遮罩层包含「更换头像」和「恢复默认」两个按钮
3. 点击「恢复默认」→ 确认弹窗 → 清除背景图 → 显示首字母
4. 调用后端接口清空 `avatarUrl`

### 8.4 涉及文件

| # | 文件 | 改动内容 |
|---|------|----------|
| 1 | `web/profile-user.jsp` | 头像遮罩加「恢复默认」按钮 |
| 2 | `web/js/profile.js` | 加恢复默认逻辑（调用 `PUT /api/users/me` 清空 `avatarUrl`） |
| 3 | `web/css/profile.css` | 加分隔符和悬停样式 |
