# 测试与完善任务清单：双人分工

> [文档总目录](../../README.md) · [系统测试文档入口](README.md)

本清单用于本轮测试和完善。两人分别负责各自模块的测试、问题修复与复测，测试结果按本轮实际执行情况记录。

## 人员 A：账号、首页与二手交易

- [ ] 测试注册、登录、退出，以及首页推荐、搜索、筛选和待办跳转。
- [ ] 完成二手交易闭环：发布商品、管理员审核、购买、交付、确认收货；检查双方订单状态和记录。
- [ ] 测试买卖双方发起终止，以及撤回、拒绝、同意后的状态；验证终止后重新交易。
- [ ] 测试商品的修改、删除、图片上传、评论和分页，以及异常输入和权限限制。
- [ ] 测试二手订单双方评价，包括重复评价、未完成订单评价、删除商品后的历史评价。
- [ ] 核对商品审核、交易进度和终止产生的消息，包括接收人、内容和订单跳转。
- [ ] 测试重复提交、越权操作和同时购买；检查 Chrome 下的桌面及窄屏页面。
- [ ] 运行 Java 和前端自动化测试，修复负责范围内的问题并复测。

## 人员 B：跑腿、个人空间、管理与消息中心

- [ ] 完成跑腿交易闭环：发布任务、管理员审核、接单、送达、确认完成；检查双方订单状态和记录。
- [ ] 测试双方发起终止，以及撤回、拒绝、同意后的状态；验证终止后修改和重新接单。
- [ ] 测试任务的修改、删除、图片上传、评论和分页，以及异常输入和权限限制。
- [ ] 测试个人资料、头像、密码、个人记录，以及管理员审核和用户管理。
- [ ] 测试跑腿订单双方评价，以及个人空间的待评价、评价记录和分页。
- [ ] 测试消息中心的未读数、分类、分页、单条及全部已读、账号隔离、断网重试和页面返回；核对跑腿相关消息。
- [ ] 测试会话失效、越权操作、重复提交和同时接单；检查 Edge 下的桌面及窄屏页面。
- [ ] 运行数据库和迁移测试，检查 JAR/WAR 部署、图片资源和重启后的数据；修复负责范围内的问题并复测。

## 两人共同完成

- [ ] 使用相同版本代码，各自准备独立测试数据库和图片目录。已有数据库先备份并使用增量迁移；初始化脚本只用于新测试库。
- [ ] 记录每项结果和缺陷，包括复现步骤、预期与实际结果、严重程度、负责人和复测结果。
- [ ] 修复完成后分别回归各自主流程，汇总未解决问题，并整理测试结果和交付说明。
