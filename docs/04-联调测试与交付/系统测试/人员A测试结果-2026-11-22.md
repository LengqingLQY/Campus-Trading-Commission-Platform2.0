## 缺陷与复测

### A-20261122-01 前端 api.js FormData 判断引用未定义变量

| 项目 | 内容 |
|---|---|
| 严重程度 | P2 |
| 关联用例 | 自动化回归（api-client.test.js） |
| 复现步骤 | 运行 `node --test web/tests/*.test.js` |
| 预期结果 | 全部通过 |
| 实际结果 | `api-client.test.js` 报 `ReferenceError: FormData is not defined`（api.js 第 28 行 `config.body instanceof FormData`），导致 1 项失败。根因是头像上传 FormData 兼容改动未做空值保护，Node vm 测试环境无 FormData 全局。 |
| 修复内容 | api.js 改为 `const isFormData = typeof FormData !== "undefined" && config.body instanceof FormData;` 再判断，避免引用未定义变量。 |
| 复测结果 | 通过。`node --test web/tests/*.test.js` 17 项全部通过。 |
