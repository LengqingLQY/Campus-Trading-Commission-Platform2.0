## 缺陷与复测

### B-20261113-01 发布接口遗漏任务标题上限

| 项目 | 内容 |
|---|---|
| 严重程度 | P2 |
| 关联用例 | ST-050 |
| 复现步骤 | 向 `POST /api/tasks` 提交 81 字标题及合法取送地点、金额 |
| 预期结果 | 返回 400，与发布页面及修改接口的 80 字上限一致 |
| 实际结果 | 返回 200，创建超长标题任务 |
| 修复内容 | 在 `TaskService.validateTaskDto` 共用标题上限校验，发布时去除首尾空白，移除修改入口重复检查 |
| 复测结果 | 通过。发布与修改的 81 字标题均返回 400，非法输入未新增任务；80 字标题加两端空白可保存为去空白后的标题。Java 46 项及 HTTP 13 个测试方法通过 |
