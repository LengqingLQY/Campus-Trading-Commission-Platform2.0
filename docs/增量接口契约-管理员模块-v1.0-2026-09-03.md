# 增量接口契约：管理员模块 v1.0

| 项目 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | 2026-09-25 |
| 基线文档 | `docs/接口契约.md`、`docs/后端设计说明书.md` |
| 变更性质 | 结束「管理员功能延期」，正式开放 `/api/admin/**` |
| 涉及前端 | `auth.js`、`api.js`、`sidebar.jsp`、`profile-admin.jsp`、`admin.js`、`profile.js`、`task-publish.jsp/js`、`product-publish.jsp/js` |
| 涉及后端 | `AdminInterceptor`、`AdminController`、`AdminService`、`AdminAuditDTO`、`TaskDAO`、`ProductDAO`、`UserDAO` |

## 1. 变更目标

1. 管理员登录后进入管理面板，侧边栏出现「管理员面板」入口。
2. 任务/商品审核（通过/驳回）、软删除（下架）。
3. 用户列表、编辑他人资料、重置密码（不含封禁）。
4. **开启审核**：新发布的任务/商品先 `audit_status='pending'`，管理员通过后才进入公开列表/大厅。

## 2. 权限模型

- 新增 `AdminInterceptor` 拦截 `/api/admin/**`，session 中 `user.role != 'admin'` 返回 `403`。
- 注册在 `AuthInterceptor` 之后：先登录校验（401），再角色校验（403）。
- 预设管理员账号 `admin/admin123`（`init_db.py`，id=1，role=admin）。

## 3. 发布规则变更

`POST /api/tasks`、`POST /api/products` 落库 `audit_status` 由 `'approved'` 改为 `'pending'`；业务 `status` 仍为 `open` / `on_sale`。

- 公开列表/详情仍走 `v_public_task` / `v_public_product`（过滤 `approved + 未删除`），pending 内容自然不可见。
- `accept/deliver/complete/buy` 已校验 `audit_status='approved'`，pending 内容不可操作。
- 发布成功前端跳转个人空间「我发布」列表并提示「等待管理员审核」；该列表对 pending/rejected 项显示审核标签、不可点击详情。

## 4. 新增接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/stats` | `{pendingTasks, pendingProducts, userCount, totalTasks}` |
| GET | `/api/admin/tasks?auditStatus=&keyword=&page=&size=` | 任务列表（原始表，排除已软删除） |
| PUT | `/api/admin/tasks/{id}/audit` | body `{approve:bool, remark?}`；驳回 remark 2~200 字 |
| DELETE | `/api/admin/tasks/{id}` | 软删除（`is_deleted=1`） |
| GET | `/api/admin/products?auditStatus=&keyword=&page=&size=` | 商品列表 |
| PUT | `/api/admin/products/{id}/audit` | 同上 |
| DELETE | `/api/admin/products/{id}` | 软删除 |
| GET | `/api/admin/users?keyword=&page=&size=` | 用户列表 |
| PUT | `/api/admin/users/{id}` | body `{username,qq,wechat,phone}` |
| PUT | `/api/admin/users/{id}/reset-password` | body `{password}`，≥6 位 |

- `auditStatus` 取值 `pending`/`approved`/`rejected`，缺省表示不过滤。
- 审核只改 `audit_status` / `audit_remark`，不改业务 `status`（数据库设计约定）。

### 错误响应

| HTTP | msg | 场景 |
|---:|---|---|
| `401` | `请先登录` | 未登录 |
| `403` | `无管理员权限` | 已登录但 role != admin |
| `400` | `approve 不能为空` / `驳回理由需为 2～200 字` / `密码至少 6 位` / `昵称不能为空` / `auditStatus 不合法` | 参数非法 |
| `404` | `任务/商品/用户不存在或已删除` | 资源不存在 |

## 6. 前端交互验收

1. `admin/admin123` 登录 → 自动进 `profile-admin.jsp`，侧边栏出现「管理员面板」。
2. 统计卡显示待审核任务/商品、注册用户数、全部任务数。
3. 待审核 Tab 列出 `init_db.py` 的 pending 样本，可「通过」或「驳回（填理由）」。
4. 普通用户发布新任务/商品 → 跳个人空间见「待审核」，大厅/市场不出现；admin 通过后出现。
5. 用户 Tab：编辑昵称/联系方式、重置密码后可用新密码登录。
6. 软删除任务/商品 → 从公开列表与个人空间消失，DB 中 `is_deleted=1` 保留。
