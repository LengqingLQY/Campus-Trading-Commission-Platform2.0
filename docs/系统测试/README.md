# 系统测试文档入口 v1.1

当前执行方式：两人各自在家使用本机 Tomcat、后端和测试数据库，独立测试，不需要远程合作。采用 **v1.1 本地独立分工**，不安排具体时间、不设组长。

## 组员从这里开始

1. 阅读 [新版总计划](系统测试计划-本地独立双人分工-v1.1-2026-09-08.md)。
2. 各自打开任务清单：**[A 的任务（32项）](本地独立测试任务-A-v1.1-2026-09-08.md)** ／ **[B 的任务（32项）](本地独立测试任务-B-v1.1-2026-09-08.md)**，直接填写执行结果。
3. 准备数据库及登录账号，查看 [测试数据库使用与恢复](测试数据库使用与恢复-v1.0-20260908-132910.md)。其中绝对路径是创建者本机路径，其他组员需对应到自己的项目位置。
4. 运行本机自动化检查，历史结果见 [自动化基线摘要](系统测试自动化基线摘要-v1.0-2026-09-08.md)。历史通过不能代替自己机器的验证。

本文件夹只集中说明文档。测试数据库基线及原库备份仍在项目 backups 目录，图片仍在 uploads；发送给组员时需要另行提供测试基线与相应测试图片，原库备份留在本机即可。
