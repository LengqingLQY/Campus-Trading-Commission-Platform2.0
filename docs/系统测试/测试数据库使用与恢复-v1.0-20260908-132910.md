## 恢复

先停止后端，关闭数据库编辑器，将原库备份复制回运行库路径，再启动后端并重新登录。若发现app.db-wal或app.db-shm，不直接文件覆盖，改用SQLite backup API恢复。需要复位测试时，使用测试基线。不要执行初始化脚本重建原库。

本次没有修改schema、后端代码或其他位置的app.db。图片地址使用localhost:8081，适用于当前本机测试。
