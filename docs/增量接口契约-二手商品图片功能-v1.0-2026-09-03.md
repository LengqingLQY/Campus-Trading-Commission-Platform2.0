# 增量接口契约：二手商品图片功能 v1.0

| 项目 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | 2026-09-25 |
| 基线文档 | `docs/接口契约.md`、`docs/增量接口契约-图片功能-v1.0-2026-09-02.md` |
| 变更性质 | 增量说明，不覆盖或修改基线文档 |
| 涉及前端 | `product-publish.jsp`、`product-publish.js`、`secondhand.jsp`、`market.js`、`product-detail.jsp`、`product-detail.js` |
| 涉及后端 | `ProductCreateDTO`、`ProductDAO`、`ProductService` |

## 1. 变更目标

在已完成的跑腿任务图片功能基础上，把二手商品对称地接通图片能力：

1. 二手商品发布时支持上传 1～3 张图片。
2. 二手商品列表卡片展示首张图片作为缩略图。
3. 二手商品详情页以平铺方式展示全部图片。

头像上传、恢复默认头像、图片上传接口（`POST /api/upload/image`）等已由基线文档覆盖，本次不新增接口。

## 2. 数据库

`product.image_urls`（TEXT，逗号分隔的图片 URL）字段已在图片功能增量契约 §2 建好，本次仅将其从「暂未接接口」接通到后端读写。

## 3. 后端改动清单

| # | 文件 | 改动内容 |
|---|------|----------|
| 1 | `ProductCreateDTO.java` | 新增 `imageUrls` 字段（选填） |
| 2 | `ProductDAO.java` | `findPublic` / `findPublicDetail` 查询增加 `image_urls`；`insert` 写入 `image_urls` |
| 3 | `ProductService.java` | `createProduct` 落库 `imageUrls`（去首尾空白，空串转 `null`） |

说明：`GET /api/public/products` 与 `GET /api/public/products/{id}` 返回字段增加 `imageUrls`；`POST /api/products` 请求体支持选填 `imageUrls`。个人空间 `GET /api/me/products` 查询走 `p.*`，无需额外改动即已带出 `imageUrls`。

## 4. 前端改动清单

| # | 文件 | 改动内容 |
|---|------|----------|
| 1 | `web/product-publish.jsp` | 引入 `image-upload.css/js`；预览区改为图片上传区域 |
| 2 | `web/js/product-publish.js` | 接入 `ImageUploadManager`，提交时携带 `imageUrls` |
| 3 | `web/js/market.js` | 列表卡片首图缩略图（复用 `imageUrls` 首张） |
| 4 | `web/product-detail.jsp` | 引入 `image-upload.css` |
| 5 | `web/js/product-detail.js` | 详情页平铺展示图片 |
| 6 | `web/css/image-upload.css` | 新增详情页平铺样式 `.detail-image-grid/.detail-image-item` |
| 7 | `web/css/secondhand.css` | 带图卡片隐藏装饰圆（`.product-visual--has-image`） |

## 5. 前端交互验收

1. 二手发布页预览卡片可点击上传图片，最多 3 张，上传后显示缩略图、悬停显示删除按钮。
2. 二手列表卡片有首图时展示缩略图，无图时保持原有分类 emoji。
3. 商品详情页有图时平铺展示全部图片，无图时保持原有分类占位图。
