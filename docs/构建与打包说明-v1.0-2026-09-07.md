# CTCP 构建与打包说明 v1.0

| 项目 | 内容 |
|---|---|
| 版本 / 日期 | v1.0 / 2026-09-28 |
| 构建入口 | 仓库根目录的 `pom.xml` |
| Java 版本 | JDK 23 |
| Maven Wrapper | 3.3.4 `only-script` |
| Maven 版本 | 3.9.16 |

## 1. 环境要求

只需安装 JDK 23，不要求全局安装 Maven。首次运行 Maven Wrapper 时需要访问 Maven Central；下载完成后会复用本机缓存。

先确认 JDK：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-23'
& "$env:JAVA_HOME\bin\java.exe" -version
```

如果 JDK 安装在其他目录，请将 `JAVA_HOME` 改为实际路径。

## 2. 从仓库根目录打包

Windows PowerShell：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-23'
.\mvnw.cmd clean package
```

Linux 或 macOS：

```bash
JAVA_HOME=/path/to/jdk-23 sh ./mvnw clean package
```

已全局安装 Maven 时也可以执行：

```powershell
mvn clean package
```

根 `pom.xml` 会依次构建后端和前端。任一模块失败时，整个命令返回失败，不会误报完整打包成功。

## 3. 打包产物

| 模块 | 产物 | 用途 |
|---|---|---|
| Spring Boot 后端 | `backend-java/target/campus-errand-backend-1.0-SNAPSHOT.jar` | Java 23 直接启动的可执行 JAR |
| JSP 前端 | `web/target/CTCP.war` | 部署到 Tomcat 8080，默认上下文路径为 `/CTCP` |

前端 WAR 不包含 `web/tests`、模块 `pom.xml` 或 `target` 构建目录。

## 4. 运行后端产物

应从仓库根目录启动，使默认数据库路径解析为 `backend/db/app.db`：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-23'
& "$env:JAVA_HOME\bin\java.exe" -jar .\backend-java\target\campus-errand-backend-1.0-SNAPSHOT.jar
```

需要从其他目录启动时，显式设置数据库与上传目录：

```powershell
$env:CTCP_DB_PATH = 'E:\project\CTCP\CTCP\backend\db\app.db'
$env:CTCP_UPLOAD_DIR = 'E:\project\CTCP\CTCP\uploads'
java -jar campus-errand-backend-1.0-SNAPSHOT.jar
```

## 5. Wrapper 完整性

`.mvn/wrapper/maven-wrapper.properties` 固定 Maven 3.9.16，并保存发行 ZIP 的 SHA-256。Wrapper 在首次下载后会先校验文件，校验失败时中止构建。

可用以下命令核对实际版本：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-23'
.\mvnw.cmd --version
```
